# AFTERGLOW — Cinematic City Guide Demo

Static, standalone HTML/CSS/JavaScript homepage based on the approved Version 6 preview.

## Local preview
Double-click `index.html` to open in a browser. Images, video and fonts load from external URLs and require internet access.

## Deploy to Vercel via GitHub
1. Create a new GitHub repository, e.g. `afterglow-city-demo`.
2. Upload `index.html` at the repository root (README optional).
3. In Vercel, choose **Add New → Project**, import this repository.
4. Framework preset: **Other**; leave Build Command empty. Root Directory: `./`.
5. Deploy. Vercel will serve `index.html` from the root.

## Scope
Visual portfolio concept only. Event listings are illustrative; no backend, Excel import, admin portal, or real event database is connected. External media availability is not guaranteed.
